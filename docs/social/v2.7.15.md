# ColaMD CT v2.7.15 Social Copy

发布方式：正式版（ColaMD CT 第一个公开版本）。

## 主文案（直接发）

ColaMD CT 2.7.15 发布，这是 ColaMD（MIT，marswave.ai 出品）社区增强版的第一个公开版本：UI 与官方版完全一致，在其「文本优先」架构上补齐三块 Typora 级能力。

- 图片工作流：粘贴、拖拽、命令三种方式插图，图床上传（PicGo、GitHub、SM.MS、自定义 HTTP）失败自动降级为本地副本。
- 表格编辑：右键菜单增删行列、调整对齐、移动与删表；渲染态单元格就地编辑，Tab 导航，末格 Tab 加行，表头拖拽调列宽。
- 快捷键全家桶：Typora 默认键位全覆盖，偏好设置里可任意改绑，菜单与键盘同步生效。
- Windows 标题栏菜单主题化：汉堡按钮弹出跟随主题的自绘菜单，偏好设置独立成行。
- 设为默认应用：macOS、Windows、Linux 三平台可用。
- 三平台安装包：macOS dmg / pkg（双架构）、Windows 安装器 / 便携 zip、Linux AppImage / deb（未签名，mac 首次打开需右键 → 打开）。

基于 ColaMD v2.7.12 修改，遵循 MIT 许可证，原版权与许可声明保留。

## English

ColaMD CT 2.7.15 is out: the first public release of the community-enhanced fork of ColaMD (MIT, by marswave.ai). The UI is identical to upstream; three Typora-grade capabilities are added on top of its text-first architecture.

- Image workflow: paste, drag-drop or command to insert; upload to PicGo, GitHub, SM.MS or a custom HTTP endpoint, with automatic fallback to a local copy on failure.
- Table editing: add or remove rows and columns, change alignment, move or delete tables from the context menu; edit cells in place while rendered, Tab navigation, Tab in the last cell appends a row, drag headers to resize columns.
- Full keyboard shortcuts: every Typora default covered, freely rebindable in Preferences, menus and keyboard stay in sync.
- Themed Windows title-bar menu: the hamburger button opens a self-drawn menu that follows the theme.
- Set as default app: works on macOS, Windows and Linux.
- Installers for all three platforms: macOS dmg / pkg (both architectures), Windows installer / portable zip, Linux AppImage / deb (unsigned; on macOS, right-click → Open on first launch).
